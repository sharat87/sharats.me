## Just a calendar

[cal.sharats.me](https://cal.sharats.me)
{ .links }

An easily reachable endpoint to have a calendar to look at. No signup, no setup, no downloads, no flash and very little features. Perfect when you want to show a calendar and talk about dates when sharing your screen in a presentation or meeting.

- Mark dates with four different colors.
- Marked dates are saved in your browser's local storage, so they survive restarts.
- Right click on a date to quickly copy the date in several useful formats.
- Dark mode, for the rest of you guys.
- Hotkeys for common actions. Hit <kbd>?</kbd> for quick help.
- Remove all marks with a single click.

Considered a "finished" project, and I'm using it every day.

## Quizfish

A web-based trivia game, in the spirit of the old QuizUp. Pick a topic and play a round of ten questions solo, or challenge a friend to a live matchup. Both players get the *same* ten questions, and each question goes to whoever answers it correctly first.

- Accounts with email verification, and friends added by username.
- Matches run live, so you see your friend's answers as they happen.
- Invite someone by email, and you start out as friends when they sign up.

## DashQL

A superlightweight webapp that turns your data into things you can use every day: dashboards to read, scheduled jobs to keep it moving, and API endpoints your apps can read and write through. The data can come from Postgres databases you already run, any HTTP API, or both. No new service per app, no SDK, no queue.

- Connect your databases and API keys once. Dashboards and scripts refer to a database by its name and never touch the credentials.
- Dashboards are a small JavaScript function that returns widgets, like tables built straight from a SQL query.
- Scripts run on a schedule, and the home page shows the ones whose last run failed, with a one-click "Fix with agent".
- An API endpoint is just a SQL statement.
- An assistant that can write all of it for you, from a plain request.

## MyPortal

A builder for single-page websites, the kind you'd put behind the link in your bio. Instead of a form full of settings, you describe what you want in a chat, and an AI agent builds and restyles the page for you.

- Links, headings, text, social icons, images, and embeds like YouTube, Calendly and Spotify.
- Click on any part of the page to point the agent at it, or mention it with `@` in your message.
- The agent sees a screenshot of the page as it is, so "fix the layout" works without explaining what's wrong.
- Every change is a checkpoint in the history, and you can go back to any of them. Nothing goes live until you publish.

## Antigen

[Project Page](https://github.com/zsh-users/antigen)
{ .links }

A plugin manager for zsh, inspired by oh-my-zsh and vundle. This is one of the first of it's kind and has inspired many alternative plugin managers for zsh as well as other popular shells.

This is currently being maintained by the community, the zsh-users organizations on Github.
